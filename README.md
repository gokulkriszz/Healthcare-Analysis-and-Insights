# Healthcare-Analysis-and-Insights
Data cleaning  &amp; interactive dashboard in Excel Healthcare Analysis and Insights 
Healthcare Analysis and Insights – Excel Capstone Project
📌 Project Overview

This project focuses on analyzing healthcare data to identify key performance indicators (KPIs) such as patient admissions, treatment costs, and hospital resource utilization. The goal was to transform raw data into meaningful insights using Microsoft Excel.

🛠️ Tools & Skills Used

Microsoft Excel

Data Cleaning & Validation

Advanced Functions (VLOOKUP, INDEX-MATCH, IF, Nested Formulas)

Pivot Tables & Pivot Charts

Conditional Formatting

Dashboard Design

Data Analysis & Visualization

Business Insights & Reporting

📊 Key Insights

Identified trends in patient admissions over time.

Analyzed treatment costs to highlight high-expense categories.

Measured resource utilization for better hospital efficiency.

Designed an interactive Excel dashboard for decision-making.

📂 Project Files

Healthcare Analysis and Insights_Excel Capstone Project.xlsx – Main project file with cleaned data, analysis, and dashboard.

🚀 How to Use

Download the Excel file from this repository.

Open in Microsoft Excel (2016 or later recommended).

Navigate through the sheets and dashboard to explore insights.
